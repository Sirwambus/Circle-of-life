# Türen – Kreis der Spiele

Eine Von-Neumann-Sonde im All, trainiert im Kreis der Spiele: 96 kleine Spiele mit je 10 Leveln in sechs Kategorien.
Geschaffte Level verbessern die Schiffssysteme der Sonde.

Läuft komplett im Browser und ist als Offline-Web-App installierbar
(iPhone/iPad: in Safari öffnen → Teilen → „Zum Home-Bildschirm“).
